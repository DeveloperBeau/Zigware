# Proposals

Design proposals for framework changes, in the style of Swift Evolution. Each
proposal is one markdown file that describes a change before anyone builds it.

## Naming

Files are numbered `NNNN-kebab-title.md` with a four-digit zero-padded number,
assigned in order. Reference a proposal by its id, `ZW-NNNN`. Copy
[0000-template.md](0000-template.md) to start a new one.

## Status

- Draft: written, not yet reviewed.
- In Review: under discussion.
- Accepted: approved to build.
- Implemented: shipped, and the proposal links the PR.
- Rejected or Withdrawn: not proceeding, kept for the record.
